# MindMap — итоговый отчёт

Нативное приложение интеллект-карт для **Mac (macOS 14+)** и **iPad (iPadOS 17+)** на SwiftUI: скорость и вид XMind, вложения как в Mindjet. Один мультиплатформенный таргет, без сторонних зависимостей.

Состояние на 2026-11-13: дорожная карта (Stage 1, Stage 2, WP7–WP17 и финальный проход) выполнена. Сборка Mac и iPad Simulator — 0 ошибок, 0 предупреждений. Тесты (Swift Testing): **macOS — 513, iPad Simulator — 476**, все зелёные; полные прогоны выполнены дважды подряд на каждой платформе.

Всё, что осталось, требует либо вашего Apple-аккаунта / устройства, либо продуктового решения — см. раздел 5.

## 1. Что умеет приложение

### Карта и редактирование
- **Темы**: центральная, главные, подтемы, плавающие (двойной клик по пустому месту). Каждое действие — ровно один шаг отмены (⌘Z / ⇧⌘Z), включая групповые.
- **Многострочные темы** (новое): во время ввода **⇧Return** или **⌥Return** — новая строка, **Return** — готово. Текст переносится по ширине 240 pt, на карте видно до 8 строк (полностью — в редакторе). Там, где тема показывается одной строкой (списки, хлебные крошки, экспорт в Markdown), строки склеиваются через пробел.
- **Копировать / вырезать / вставить** (новое): ⌘C / ⌘X / ⌘V (на Mac — меню Edit, на iPad — аппаратная клавиатура), а также Cut / Copy / Paste в контекстном меню и в «More» на iPad. Копируется ветка целиком: стили, задачи, ссылки, заметки, рисунки, файлы, связи и границы внутри неё. Вставка — внутрь выбранной темы, без выбора — плавающей темой в центре экрана; работает между картами и окнами. Текст из других приложений вставляется темами: строка = тема, отступ (Tab или 2 пробела) = вложенность, маркеры списков убираются, `- [ ]` / `- [x]` становятся задачами. В другие приложения уходит оглавление с табуляцией. Заблокированные заметки (Lock Note) не копируются: их ключ привязан к заметке.
- **Выделение нескольких тем**: ⌘-клик, ⇧-клик (диапазон), ⌘A, рамка (⇧/⌘ + протянуть по фону); на iPad — кнопка Select, а теперь и ⌘-тап / ⇧-тап с аппаратной клавиатуры. Удаление, перенос, формат, задачи, границы — сразу для всех.
- **Перетаскивание**: на тему — перенос, на край — вставка до/после, на пустое место — свободная позиция (⌥-перетаскивание на Mac — всегда свободно). Reset Position / Reset All Positions.
- **Свёртывание**: кнопка −/+N, ⌘/, ⌥⌘1…4 / ⌥⌘0, Expand/Collapse Branch. Тема остаётся на месте экрана, остальное плавно перестраивается (в том числе при ⌘Z).
- **Стабильная раскладка**: главные ветки не меняют сторону сами; View ▸ Rebalance Map — явная перебалансировка. Наложений тем, границ, плавающих тем и панели задач нет.

### Вид (стиль XMind)
- Раскладки на любой ветке: Map (сбалансированная), Logic Right / Left, Tree Down, Org Chart.
- Темы оформления XMind Pastel (по умолчанию), Classic Rainbow, Mono; формы, рамки, цвета, линии (кривая, прямая, угол, скруглённый угол; сплошная / пунктир / точки; толщина), «применить к ветке».
- **Связи** (⌘L): кривые со стрелками, подпись прямо на холсте, контрольные точки.
- **Границы** (⌘B): вокруг любых выбранных тем, даже из разных веток; контур обходит чужие темы. Новое: перемычка контура больше не проходит через другие границы и старается не идти по линиям связей.

### Ссылки
- ⌘K: **веб-адрес**, **другая тема** этой карты, **другая карта** (`.mindmap` или карта библиотеки), по желанию — сразу на её тему. Переход — клик/тап по значку ссылки; ⌘[ — назад.
- Карта открывается вкладкой (Mac) или отдельным окном (iPad); уже открытая — выводится вперёд.
- Новое: **значок ссылки на карту бледнеет, если файл пропал** (проверка при открытии карты, изменении ссылок и возвращении в приложение); клик по нему предлагает Locate….
- Новое: если ссылку создали кнопкой **New Map…**, ⌘Z убирает и ссылку, и только что созданный файл (если его не открывали и не меняли); ⇧⌘Z возвращает файл.

### Задачи
- Task ▸ Convert to Task: флажок, приоритет (!!! / !! / !), срок (Today, Tomorrow, …, просроченные — красным). ⌘Return — выполнено. Для нескольких выбранных тем — сразу для всех.
- **Панель Tasks** на холсте: все открытые задачи; клик — переход к теме, флажок — выполнить; панель можно перетащить (темы её обходят). Новое: длинный список после «Show N More» прокручивается внутри панели (до 20 строк по высоте; колесо мыши над списком прокручивает его, а не холст); на карте «только чтение» перетаскивание панели двигает холст.

### Вложения
- **Заметки Markdown** (⇧⌘N) — обычные `.md` внутри пакета (читаются в Obsidian), Edit / Preview. Новое: Preview показывает таблицы, заголовки `===` / `---`, вложенные цитаты, все варианты списков и задач, блоки кода ``` и ~~~, зачёркивание, ссылки, вместо картинок — их подпись.
- **Рукописные заметки** (⇧⌘D): PencilKit на iPad (полный экран, палитра, Pencil рисует, пальцы листают); на Mac — просмотр и простое рисование мышью.
- **Файлы** (⇧⌘A, перетаскивание из Finder / Files, ⌘V): копия внутри пакета, QuickLook, Share / Open / Export.
- Значки на теме маленькие (≤3 — по одному на вложение, больше — по одному на тип + счётчик). Новое: **значки переставляются перетаскиванием значка вбок**.
- Пустая заметка исчезает при закрытии; кнопка корзины удаляет заметку / рисунок / файл. На Mac окно заметки всегда над картой, даже в полноэкранном режиме.

### Welcome и примеры
- Mac: окно **Welcome** (⇧⌘1): New Map, Open…, Open Sample, библиотека iCloud Sync, последние файлы (поиск, миниатюры). iPad: стартовый экран и папка ▸ Welcome.
- Первый запуск: тур (6 страниц) с выбором хранилища, затем открывается пример **«MindMap Features»** — живая инструкция по всем функциям с веткой **Hotkeys** (все сочетания клавиш, собраны из кода) и вторая карта «MindMap Roadmap». Help ▸ Welcome Tour открывает тур снова.
- Новое: в списках Welcome и библиотеки у карт с Lock Editing — значок «только чтение» (перечёркнутый карандаш). В iPad настройки открываются большим листом.

## 2. Как пользоваться

Полный и актуальный список клавиш — ветка **Hotkeys** в примере «MindMap Features» (Welcome ▸ Open Sample). Самое нужное:

**Mac**
- Tab — дочерняя тема, Return — соседняя, Delete — удалить, Space / F2 / просто печатать — переименовать; во время ввода ⇧Return / ⌥Return — новая строка.
- Двойной клик по теме — дочерняя тема; по пустому месту — плавающая тема; правый клик — меню.
- ⌘C / ⌘X / ⌘V — ветки; ⌘K — ссылка; ⌘L — связь; ⌘B — граница; ⇧⌘N / ⇧⌘D / ⇧⌘A — заметка / рисунок / файл; ⌘Return — задача выполнена.
- ⌘/ — свернуть; ⌥⌘1…4 / ⌥⌘0 — уровни; ⌘= / ⌘- / ⌘0 — масштаб; ⌘-колесо или щипок — зум.
- ⌥⌘L — Lock Editing (только чтение); File ▸ Lock Map… — шифрование; ⌃⌘L — Lock Now.
- ⌘N — новая карта (в библиотеку или файлом, по настройке), ⇧⌘O — библиотека / Welcome, ⇧⌘1 — Welcome, ⌘, — Settings.

**iPad**
- **Тап** по теме — выбрать и свернуть/развернуть её ветку (у листа — только выбор); над темой — панель действий (Child, Sibling, Edit, Delete, Note, Link, Task, More).
- **Двойной тап** по теме — новая дочерняя тема сразу в режиме ввода; по пустому месту — плавающая тема.
- **Долгое нажатие** — всё меню темы. **«+»** у выбранной темы — дочерняя. **Select** — выбор нескольких тапами и рамкой.
- Переименовать: Edit на панели, Rename в меню, Space / F2 на клавиатуре или написать поверх темы Pencil (Scribble).
- **Apple Pencil**: тап = палец; наведение (iPad Pro) подсвечивает тему и «+»; сжатие (Pencil Pro) — панель действий; двойной тап по карандашу — дочерняя тема. В рукописной заметке Pencil рисует, пальцы листают.
- Аппаратная клавиатура: те же сочетания, что на Mac (удерживайте ⌘ — система покажет список); ⌘-тап / ⇧-тап — выделение нескольких.
- Справка по жестам: «…» ▸ Gestures & Apple Pencil (один раз показывается при первом запуске).

## 3. Хранение, синхронизация и замки

**Карта** — пакет `.mindmap`: `map.json` (дерево) + `attachments/` (заметки `.md`, рисунки PencilKit, файлы). Абсолютных путей нет; старые файлы открываются; неизвестные поля и виды ссылок сохраняются.

**Два режима хранения** (Settings ▸ Storage; определяет, куда идёт New Map):
- **iCloud Sync** — собственная библиотека приложения в CloudKit (приватная база вашего Apple ID). Работает **без iCloud Drive** и офлайн (локальный кэш); при конфликте объединяет изменения **по темам**: разные темы — обе правки, одно поле — более новая, одновременная правка текста — оба варианта (второй рядом, с пометкой «conflicting edit»). Заблокированные карты уходят в облако только зашифрованными. Для карт библиотеки есть Rename, Duplicate, Export as File…; Move To… запрещён (это удалило бы карту из облака).
- **Files** — обычные `.mindmap` в выбранной папке (в том числе в iCloud Drive). Import to Library / Move to Library… переносят файл в библиотеку. Открыть `.mindmap` с диска можно всегда, в обоих режимах.
- **Mirror to folder** (Settings): каждая карта библиотеки дублируется в выбранную папку простым `.md` (для Obsidian), только в одну сторону; заблокированные — никогда.

**Lock Map / Lock Note** (настоящая защита): AES-256-GCM, свой ключ на каждую карту/заметку в **iCloud Keychain**, открытие — Face ID / Touch ID / пароль устройства. Автоблокировка: уход в фон (iPad), бездействие (Settings ▸ Lock, по умолчанию 5 мин), сон / блокировка экрана Mac, Lock Now ⌃⌘L. На диске — только зашифрованные файлы. **Ключа восстановления нет (ваш выбор): потеря iCloud Keychain = потеря доступа к заблокированным картам.**

**Lock Editing** (⌥⌘L, замок в панели инструментов) — не защита, а режим «только чтение»: можно смотреть, сворачивать, переходить по ссылкам, открывать заметки; правки, перетаскивание и вставка блокируются с подсказкой «Map is locked». Сохраняется в карте и синхронизируется.

## 4. Что проверить вручную (только на устройстве)

Всё перечисленное покрыто логикой и тестами, но настоящие касания, Pencil, клавиатуру iPad и облако в симуляторе не проверить.

**iPad, касания и Pencil**
1. Тап по теме с детьми — сворачивает/разворачивает, тема на месте; двойной тап — новая дочерняя тема с клавиатурой; долгое нажатие — меню.
2. Перетаскивание темы пальцем: на тему, между соседями, на пустое место. Перетаскивание значка заметки вбок меняет порядок значков и не тянет тему.
3. Pencil: Scribble поверх темы (переименование), наведение, сжатие, двойной тап; в рукописной заметке — отклонение ладони, ⌘Z, жест тремя пальцами.
4. Экранная клавиатура: редактирование темы или подписи связи у нижнего края — холст сдвигается, поле видно; Return на экранной клавиатуре завершает ввод.
5. Аппаратная клавиатура: Tab (дочерняя тема; в листах цвета / ссылки — переход между полями, в заметке — табуляция), F2, ⇧Return (новая строка), ⌘C / ⌘X / ⌘V, ⌘-тап и ⇧-тап по темам, ⌘A, ⌘Z.
6. Трекпад: панорама двумя пальцами, щипок, правый клик.
7. Два окна (Split View / Stage Manager) с разными картами; ссылка на карту открывает второе окно.

**Mac**
8. Touch ID при открытии заблокированной карты; Lock Now ⌃⌘L; автоблокировка через минуту.
9. Перетаскивание файлов из Finder на тему и на холст; Export… / Open у файла.
10. ⌘C на ветке → ⌘V в другой карте (соседняя вкладка): ветка вместе с заметками и файлами.
11. Ссылка через New Map… → ⌘Z: файл исчез; ⇧⌘Z: вернулся.

**Облако и ключи (после шага B1)**
12. Settings ▸ Storage показывает «Synced». Карта, созданная на Mac, появляется на iPad и наоборот; переименование и удаление доходят.
13. Правка одной карты офлайн на двух устройствах (разные темы, затем одна и та же тема) — объединение и копия «conflicting edit».
14. Карта, заблокированная на iPad, открывается на Mac (ключ из iCloud Keychain).

### Мелкие известные ограничения (работе не мешают)
- Сложный контур границы и панель действий iPad во время анимации раскладки сразу встают в конечную форму/позицию.
- При перетаскивании группы «призраки» — только сами темы, без поддеревьев.
- Scribble или перетаскивание темы карандашом — решает система (быстрый росчерк может начать рукописный ввод).
- Очищенная заметка, пока её окно открыто, ещё показывает значок (удаляется при закрытии).
- Отмена «New Map…» убирает файл, только если его никто не открыл и не изменил; файл, созданный через окно сохранения вне папки карты, в песочнице Mac может остаться.
- Карта, переименованная синхронизацией, пока открыта на iPad, показывает старое имя до переоткрытия.
- Очень большие файлы импортируются без индикатора прогресса; временная папка вложений очищается при закрытии карты.

## 6. Сборка, запуск, DMG

Xcode установлен, но не выбран — всегда через обёртку (ставит `DEVELOPER_DIR`, подпись; без профиля Mac — локальная сборка):

```sh
# тесты Mac
Tools/xcb/xcb.sh -project MindMap.xcodeproj -scheme MindMap -destination 'platform=macOS' test
# тесты iPad Simulator
Tools/xcb/xcb.sh -project MindMap.xcodeproj -scheme MindMap \
  -destination 'platform=iOS Simulator,name=iPad Pro 11-inch (M5),OS=latest' test
# Debug-приложение для Mac → build/DD/Build/Products/Debug/MindMap.app
Tools/xcb/xcb.sh -project MindMap.xcodeproj -scheme MindMap -destination 'platform=macOS' \
  -derivedDataPath build/DD build
# Release DMG → ~/Desktop/MindMap.dmg
Tools/release/make_dmg.sh
```

- В Xcode: открыть `MindMap.xcodeproj`, схема MindMap, «My Mac» или iPad, Run.
