# MindMap — отчёт по Stage 1 (редактор дерева) и Stage 2 (вложения)

Нативное SwiftUI-приложение (iPadOS 17+ / macOS 14+), один мультиплатформенный таргет, без сторонних зависимостей.
Сборка iPad Simulator + macOS: 0 ошибок, 0 предупреждений. 101 тест (Swift Testing) зелёные на macOS и iPad Simulator.

## Что работает
**Модель и документ**
- Дерево `Node`: текст, цвет-тег или свой цвет, свёрнутость, стиль раскладки, форма, рамка, стиль/толщина/пунктир линии, вложения (пока заглушка).
- Документ-пакет `.mindmap` = `map.json` + `attachments/`. При сохранении `attachments/` и неизвестные файлы пакета переиспользуются как есть, не переписываются (в iCloud это дёшево). В JSON только UUID и относительные имена, абсолютных путей нет.
- Обратная совместимость: старый `map.json` только с `root` (даже без `formatVersion`) открывается; неизвестные значения enum заменяются значениями по умолчанию.
- Undo/redo: каждое изменение структуры и стиля — ровно один шаг (тест на 31 вид операций). Добавление темы + первое переименование — один шаг. После автосохранения переименование регистрируется отдельно, и документ снова помечается изменённым.

**Раскладка и отрисовка (стиль XMind)**
- Сбалансированная карта, вправо, влево, дерево вниз, оргсхема — на любой ветке; без перекрытий при разных размерах узлов.
- Центральная тема — жирный блок, главные ветки — цветные заливки, подтемы — подчёркнутые. Радужная или монохромная тема, цвет наследуется веткой.
- Формы, рамки, линии ветвей (кривая, прямая, угол, скруглённый угол; сужение от центра).
- Плавающие темы, связи (кривая со стрелками, подпись, перетаскиваемые контрольные точки), границы (пунктир + штриховка, подпись).
- Длинный текст переносится по ширине 240 pt и обрезается после 8 строк (полный текст виден в редакторе), поэтому узлы остаются компактными. Узел с пустым текстом имеет минимальный размер и кликабелен.
- Скорость (debug-сборка, Mac): раскладка 1000 узлов ≈ 2–3 мс; перерисовка на нажатие клавиши при 1000 узлах ≈ 4 мс. Размеры текста кэшируются, перемеряется только редактируемый узел.

**Взаимодействие**
- Клавиатура:
  - Enter — соседняя тема, Tab — дочерняя, Delete — удалить.
  - Переименовать: Space, F2, пункт «Rename» (первый в контекстном меню) или просто начать печатать на выбранной теме.
  - Стрелки — переход по соседним темам на карте.
  - Cmd+/ — свернуть/развернуть; Cmd+Option+1…4 — показать уровни 1–4, Cmd+Option+0 — развернуть всё; Cmd+Z / Cmd+Shift+Z — отмена/повтор.
  - Cmd+L — связь, Cmd+B — граница; Cmd+= / Cmd+- / Cmd+0 — масштаб.
  - Во время редактирования клавиши уходят в текстовое поле.
- Мышь и тач:
  - Тап — выбор. Двойной клик / двойной тап по теме — новая дочерняя тема (сразу в режиме ввода, как Tab). Двойной клик по пустому месту — плавающая тема.
  - Перетаскивание на центр темы — перенос; на край — вставка до/после, с индикатором; на пустое место — тема остаётся там, куда её бросили (свободная позиция, соседи перестраиваются без неё; в сбалансированной карте сторона определяется позицией). С Option (Mac) — всегда свободное перемещение, даже над темами. «Reset Position» / «Reset All Positions» возвращают авто-раскладку.
  - Тему можно тащить и во время редактирования (за край/поля вокруг текста) — текст сохраняется.
  - Перетаскивание плавающей темы — перемещение.
  - Кнопка −/+N на краю темы, откуда выходят ветки (как в MindManager): видна при наведении (Mac), у выбранной и у свёрнутой темы; клик сворачивает/разворачивает, не начиная перетаскивание.
  - Меню Outline (тулбар), View (меню Mac), контекстное меню центральной темы и пустого холста: Collapse to Level 1–4, Expand All, Reset All Positions. У темы: Expand Branch / Collapse Branch. Каждое действие — один шаг отмены.
  - Правый клик или долгое нажатие — контекстное меню.
  - Меню Format: раскладка, форма, рамка, цвет, линия, тема, «применить к ветке».
- Подписи связей и границ редактируются прямо на холсте, а не в алерте. Return, Esc или клик в сторону — сохранить; пустая подпись удаляется.
- Масштаб 0.2×–4×: pinch, на Mac также Cmd+колёсико или трекпад. Панорама — перетаскиванием фона или прокруткой.

**Запуск без выбора файла (п. 16)**
- Mac: при запуске окно выбора файла не показывается. Если macOS сама восстановила окна (или несохранённый документ), используются они. Иначе открывается последний документ из «Open Recent». Если его нет, открывается следующий из списка, а если и его нет — новая пустая карта. Другие файлы — через File → Open / Open Recent.
- iPad: браузер документов не показывается. Окно сразу открывает редактор:
  - свой документ (после перезапуска окна);
  - иначе последний открытый документ (только первое окно);
  - иначе новую карту «Untitled», «Untitled 2», …
- Новые карты сохраняются в папку приложения: Files → «На iPad» → MindMap. Если включить iCloud (см. ниже), они сохраняются в iCloud Drive → MindMap.
- Кнопка с папкой слева в тулбаре открывает меню:
  - New Map;
  - Open… — выбор .mindmap где угодно, включая iCloud Drive;
  - Rename….
- С клавиатурой: Cmd+N — новая карта, Cmd+O — открыть, Opt+Cmd+N — новое окно. Файл, открытый из Files, открывается в текущем окне.
- Каждое окно iPad редактирует свой документ, и один файл не открывается в двух окнах.
- Undo/redo, автосохранение и пометка изменений работают как раньше: документ использует undo manager окна, и его же использует системное меню Edit.
- Пустая новая карта, которую так и не изменили, удаляется при переходе к другому документу, чтобы не копились лишние «Untitled».

- Переименование новой темы после автосохранения не помечало документ изменённым.
- При переносе или отсоединении тема теперь удаляется из диапазонов соседей у границ; раньше там оставались «висячие» ссылки.
- Тема, выросшая после ввода текста, прокручивается в видимую область.
- Алерт подписи заменён на редактирование прямо на холсте.
- Новые тесты:
  - undo/redo всех операций; некорректные операции не создают шаг отмены;
  - очистка связей и границ при удалении;
  - пакет с вложениями через запись на диск; старый JSON;
  - длинный и пустой текст; пределы масштаба;
  - сворачивание ветки с выделением внутри; подписи на холсте;
  - скорость; рендер нового документа.

## Проверить вручную на iPad
1. Files / iCloud Drive:
   - создать документ, закрыть, открыть снова;
   - переименовать и переместить в Files;
   - открыть тот же файл на Mac через iCloud;
   - запуск: сразу открывается последний документ; если его удалить — новая карта; открыть файл из Files; два окна (Split View) с разными картами; Rename…;
   - правки сохраняются, в том числе после фонового автосохранения и сворачивания приложения;
   - повторное сохранение не падает.
2. Аппаратная клавиатура:
   - Tab создаёт дочернюю тему, а не переключает фокус; так же при редактировании;
   - Enter, Delete, Space, стрелки;
   - Esc — выход из редактирования и отмена режима выбора цели;
   - Cmd+Z / Cmd+Shift+Z, Cmd+/, Cmd+L, Cmd+B;
   - у новой темы выделен весь текст; ввод буквы на выбранной теме начинает редактирование.
3. Палец:
   - тап; двойной тап по теме (новая дочерняя тема) и по пустому месту (плавающая тема);
   - перетаскивание темы на пустое место (свободная позиция), кнопка −/+ у выбранной темы;
   - перетаскивание на тему и между соседями;
   - долгое нажатие — меню, тема выбирается заранее.
4. Apple Pencil: тап и перетаскивание работают как пальцем, долгое нажатие открывает меню.
5. Трекпад и мышь: панорама двумя пальцами, pinch-зум, правый клик (меню), наведение при выборе цели связи.
6. Pinch-зум пальцами: плавный, точка под пальцами остаётся на месте, пределы 0.2×–4×, текст чёткий.
7. Многозадачность:
   - два окна приложения (Split View / Stage Manager) с разными документами и с одним и тем же;
   - клавиши работают в активном окне;
   - при изменении размера окна карта не сдвигается.
8. Подпись связи или границы на холсте: экранная клавиатура не перекрывает поле.
9. Большая карта (сотни тем): плавность панорамы и набора текста.

## Известные ограничения
- Редактор темы однострочный: текст отображается с переносами, но ввести перевод строки нельзя.
- Граница — только вокруг одного поддерева: нет множественного выделения для диапазона соседей. Диапазон из файла рисуется, но места не резервирует.
- Перестановка в сбалансированной карте следует порядку детей: после перебалансировки ветка может перейти на другую сторону.
- На iPad нет контекстного меню пустого холста (вместо него — двойной тап и меню Insert в тулбаре).
- Tab на iPad перехватывается холстом на уровне окна: в текстовых полях листов (например, hex-цвет) Tab не переключает поля.
- Не проверено автоматически:
  - XCUITest невозможен в этой среде (Automation Mode выключен и требует подтверждения пользователя). Вместо него `CanvasEventTests` подают синтезированные события мыши в настоящий SwiftUI-холст на macOS — и в отдельном окне, и в реальном окне документа DocumentGroup (тулбар, меню, монитор событий): клик, двойной клик, перетаскивание (перенос, вставка, свободная позиция, Option), панорама фоном, перетаскивание редактируемой темы, кнопка −/+. Прокрутка трекпадом, наведение и iPad-жесты так не проверены;
  - синхронизация iCloud и конфликты версий;
  - клавиатура, Pencil и трекпад на устройстве.
  Рендер проверен только снимком вне экрана (ImageRenderer) на macOS; приложение на Mac запускается.
- iCloud на iPad выключен: нужна команда разработчика (у ad-hoc и бесплатных команд iCloud нет). Чтобы включить, в Signing & Capabilities добавьте iCloud → iCloud Documents с контейнером `iCloud.com.kekukh.MindMap` (в Info.plist `NSUbiquitousContainers` уже есть). Без этого новые карты лежат в «На iPad › MindMap», а файлы из iCloud Drive открываются через Open….
- iPad: незаметно закрытое окно (не через переход в фон) сохраняется периодическим автосохранением UIDocument и при уходе приложения в фон. Конфликт версий iCloud решается в пользу текущей версии.
- Stage 2 готов (ждёт вашей проверки): WP4 Markdown-заметки, WP5 рукописные заметки, WP6 файлы — см. разделы ниже.

## Stage 2 · WP4 — Markdown-заметки
Что работает:
- У темы может быть несколько вложений. На теме справа от текста — маленькие значки: «≡» заметка, каракуля (рисунок), скрепка (файл). Больше трёх — по значку на вид и счётчик (по нажатию — список). Содержимое в карточке не показывается.
- Добавить заметку: контекстное меню темы → «Add Note», кнопка «Note» в центральной группе тулбара или ⇧⌘N (открывает первую заметку темы или создаёт новую). Новая заметка начинается строкой `# <текст темы>`.
- Открыть: нажать значок на теме или пункт в контекстном меню (там же Move Left/Right и Remove). На iPad заметка открывается листом (Done), на Mac — отдельным окном.
- Редактор: поле заголовка, простой текстовый редактор Markdown (моноширинный шрифт — переключатель «Aa»), Edit/Preview, Undo/Redo. Правки заметки входят в общую историю отмены документа (⌘Z работает и в окне заметки), документ помечается изменённым и автосохраняется.
- Хранение: `Карта.mindmap/attachments/<UUID>.md` — обычный UTF-8 Markdown, открывается в Obsidian. Неизменённые файлы при сохранении не переписываются; файлы, на которые никто не ссылается, удаляются при сохранении, но удаление заметки или темы можно отменить — файл вернётся.
- Mac: окно заметки, восстановленное после перезапуска без открытой карты, показывает «Map Not Open»; при закрытии карты её окна заметок закрываются.

Проверить вручную:
1. iPad: добавить заметку, набрать текст, Done, закрыть приложение, открыть снова — текст на месте; ⌘Z в листе с аппаратной клавиатурой.
2. Mac: два окна заметок от разных карт; закрыть карту — окна закрываются; перезапуск с открытым окном заметки.
3. Открыть `attachments/<UUID>.md` в Obsidian/TextEdit через «Показать содержимое пакета».
4. Удалить тему с заметкой, сохранить, отменить — заметка и её текст вернулись.

Ограничения: Preview — упрощённый Markdown (заголовки, списки, задачи, цитаты, код, inline-стили); значки нельзя переставлять перетаскиванием (только меню).

Исправлено в WP5: при открытом листе заметки главный поток мог загружаться на 100%. Причина: окно карты и редактор вложения обновляли кнопки Undo/Redo по уведомлению checkpoint, а сама проверка `canUndo` снова отправляет это уведомление — получался бесконечный цикл. Теперь кнопки обновляются только при закрытии группы и при undo/redo.

## Stage 2 · WP5 — рукописные заметки (PencilKit)
Что работает:
- Добавить: контекстное меню темы → «Add Handwritten Note», тулбар «+» (Insert) → «Handwritten Note», меню Topic → «Add/Open Handwritten Note» или ⇧⌘D (открывает первую рукописную заметку темы или создаёт новую). На теме появляется значок-каракуля; нажатие на него открывает заметку.
- iPad: заметка открывается на весь экран (холст PencilKit + стандартная панель инструментов: ручки, маркер, ластик, линейка, цвета). Есть поле заголовка, Undo/Redo и Done.
  - По умолчанию рисует только Apple Pencil, а палец прокручивает (как в «Заметках»). Переключатель с рукой в тулбаре («Draw with Finger») разрешает рисовать пальцем; настройка запоминается.
  - Двойное касание и сжатие Pencil обрабатывает системная панель инструментов.
  - Лист «бесконечный» вниз: когда пишешь у нижнего края, страница растёт. Pinch-зум до 5×, по умолчанию страница по ширине экрана (ширина страницы 1024 pt одинакова на iPad и Mac).
  - Бумага всегда белая, чернила не инвертируются и в тёмной теме.
- Отмена: каждая серия штрихов (пауза 0,6 с, не дольше 2 с) — один шаг «Draw» в общей истории документа, вместе с картой и заметками. Встроенная отмена PencilKit отключена, чтобы шаги не дублировались. ⌘Z, жест тремя пальцами, кнопки панели Pencil и тулбара отменяют шаги документа, холст сразу показывает результат. Несохранённые штрихи записываются по Done, перед Undo и при уходе приложения в фон. Документ помечается изменённым и автосохраняется.
- Хранение: `Карта.mindmap/attachments/<UUID>.drawing` — ровно `PKDrawing.dataRepresentation()`. Удаление заметки или темы можно отменить даже после сохранения.
- Mac: заметка открывается отдельным окном (как текстовая) и показывает рисунок на белой странице. Масштаб — pinch или ⌘+колёсико; страница подгоняется по ширине окна, пока вы сами не изменили масштаб. Внизу подсказка, что полноценно рукописные заметки редактируются на iPad.
  - Бонус: простое рисование мышью. Инструменты View / Pen / Eraser, 4 цвета пера, ластик удаляет штрих целиком. Каждый штрих — шаг «Draw», ⌘Z в окне отменяет его.

Как проверено: тесты моделей и хранилища (рисунок с синтетическими штрихами сохраняется в пакет на диск и читается обратно без изменений; отмена добавления, удаления и рисования; очистка «осиротевших» `.drawing`; совместимость JSON). На симуляторе iPad сделаны и просмотрены скриншоты через DEBUG-переменную `MINDMAP_DEBUG_DRAWING=icon|sheet|undo`: холст с заранее заданным рисунком; тёмная тема; появление и исчезновение штриха при Draw/Undo; значок на теме. На Mac настоящие события мыши проверены в окне документа: клик по значку открывает окно с рисунком (снимок окна просмотрен), штрих мышью, ⌘Z, ластик.

Проверить вручную на iPad с Apple Pencil:
1. Добавить рукописную заметку из меню темы и через ⇧⌘D. Написать несколько слов. Done → значок на теме → снова открыть: всё на месте. Закрыть приложение и открыть снова: рисунок сохранился.
2. По умолчанию палец не рисует, а прокручивает; Pencil рисует. Включить «Draw with Finger»: палец рисует, прокрутка двумя пальцами. Перезапустить: настройка сохранилась.
3. Двойное касание Pencil (2-го поколения / Pro) переключает ручку и ластик; сжатие (Pencil Pro) показывает палитру у кончика.
4. Undo/Redo: кнопки тулбара, кнопки на панели Pencil, жест тремя пальцами, ⌘Z на клавиатуре. Быстро написать штрих и сразу нажать Undo — штрих отменяется, ничего не теряется. После Done ⌘Z на карте отменяет рисунок шаг за шагом, затем само добавление.
5. Писать у нижнего края: страница растёт, прокрутка вниз продолжается. Pinch-зум, поворот экрана: страница остаётся по ширине.
6. Тёмная тема: бумага белая, чёрные чернила остаются чёрными; цвета палитры не инвертируются.
7. Отклонение ладони при письме Pencil; линейка; разные инструменты (карандаш, маркер, ластик пикселей и объектов).
8. Открыть ту же карту на Mac: окно рисунка совпадает с iPad. Нарисовать мышью, вернуться на iPad — штрих виден.

Ограничения: на Mac нет полноценного редактора PencilKit (PKCanvasView там нет) — только просмотр и простое рисование мышью: перо постоянной толщины, ластик удаляет штрих целиком, без лассо. Нет миниатюры рисунка при наведении на значок. Настоящий Pencil, жесты и отклонение ладони в симуляторе не проверить — см. список выше.

## Stage 2 · WP6 — файлы-вложения
Что работает:
- Добавить файл к теме:
  - контекстное меню темы → «Attach File…», тулбар «+» (Insert) → «Attach File…», меню Topic → «Attach File…» или ⇧⌘A. Открывается системный выбор файлов, можно выбрать несколько файлов любого типа (в том числе из iCloud Drive: файл сначала скачивается);
  - перетащить файлы из Finder / приложения «Файлы» / Фото на тему: тема подсвечивается, файлы прикрепляются к ней;
  - перетащить файлы на пустое место холста: для каждого файла создаётся плавающая тема с именем файла (без расширения) и этим файлом. Почему так, а не «к выделенной теме»: бросок — жест «сюда», а прикрепление к теме далеко от места броска было бы незаметным. Плавающую тему потом можно прикрепить к дереву («Attach to…» или перетаскиванием);
  - вставить из буфера: контекстное меню темы → «Paste File»; на Mac также ⌘V на холсте (к выделенной теме, без выделения — плавающая тема в центре).
  - Папки и пакеты (например, `.key`) прикрепляются как `.zip`.
- Файл КОПИРУЕТСЯ в `Карта.mindmap/attachments/<UUID>.<расширение>`; название вложения — исходное имя файла («Отчёт Q3.pdf»). Расширение сохраняется в нижнем регистре, только если это обычное латинское слово до 16 символов; иначе (нет расширения, `.bashrc`, кириллица, пробелы) файл хранится как `<UUID>`.
- Большие файлы не держатся в памяти: копия делается системным копированием (на APFS — мгновенный клон), сохранение читает её лениво. Удалённые файлы больше 1 МБ для отмены хранятся во временной папке на диске, а не в памяти.
- На теме — значок-скрепка (больше трёх вложений — значок на вид и счётчик). На Mac при наведении — подсказка с именем файла (для свёрнутого ряда — список имён).
- Открыть (нажать скрепку или пункт меню):
  - iPad — лист с просмотром QuickLook (PDF, картинки, видео, Office, текст…), сверху имя (можно переименовать прямо в поле), тип и размер. Кнопки: Поделиться, «…» → Open In… (открыть копию в другом приложении), Rename, Remove; Done закрывает лист;
  - Mac — отдельное окно с QuickLook. Кнопки: Поделиться, Open (копия открывается в приложении по умолчанию), «…» → Export… (сохранить копию куда угодно и показать её в Finder), Rename, Remove.
  - Поделиться / открыть / экспортировать — всегда временная копия с исходным именем файла. Правки, сделанные в другом приложении, в карту НЕ возвращаются (вне рамок этапа; чтобы обновить файл, прикрепите изменённую версию заново).
- Отмена: добавление, удаление и переименование — по одному шагу в общей истории документа; после отмены удаления (даже после сохранения) файл возвращается в пакет. Файлы, на которые никто не ссылается, при сохранении удаляются из пакета, с любым расширением.

Как проверено:

QuickLook на Mac рисует в отдельном процессе, поэтому снимок окна изнутри приложения пустой, а скриншот экрана здесь запрещён; вместо этого проверено, что удалённое представление QuickLook заполняет окно, а миниатюра QuickLook той же копии отрисовывает PDF (просмотрена).

## Исправления по отзыву (партия 1, 2026-11-12)
1. **Фокус при создании темы.** Причина: запрос фокуса для поля ввода новой темы SwiftUI терял, если он приходил, пока холст ещё обрабатывал нажатие (Tab/Enter, иногда клик) — поле показывалось, но клавиатура оставалась у холста и набранный текст пропадал. Теперь поле повторяет запрос, пока реально не получит фокус, и выделяет «Subtopic» — сразу печатаете, текст заменяется. Проверено в настоящем запущенном приложении (DEBUG-проба шлёт реальные события: двойной клик, Tab, Enter, + набор) и тестами с событиями.
2. **Линия при перетаскивании.** Пока тянете тему, ветка следует за ней: от темы под курсором (будущий родитель), при вставке между соседями — от их родителя, на пустом месте — от текущего родителя. Старая линия скрыта.
3. **Наложение веток.** Причина: «Services» была перемещена вручную (свободная позиция), а такие ветки не участвовали в раскладке — соседи их «не видели». Теперь остальные ветки раздвигаются вокруг свободно поставленной ветки (выше/ниже, в дереве — только вниз, в орг-диаграмме — вбок); сама она остаётся на месте. Тесты воспроизводят вашу карту.
4. **Tree Down.** В вашей карте у Services стоял стиль Logic Right (поэтому столбец был по центру). Стиль «Tree Down» теперь: линия спускается от левой части темы, дети друг под другом с отступом, их подтемы идут вправо. Меню Layout в контекстном меню сразу после «Add Sibling Topic»: Map, Logic Right, Logic Left, Tree Down, Org Chart — с иконками и галочкой; применяется сразу (один шаг отмены).
5. **Окно заметки (Mac).** Причина: окно заметки могло становиться вкладкой/полноэкранным вместе с картой (если карта во весь экран) — без кнопок и без изменения размера. Теперь это обычное окно с кнопками закрыть/свернуть, меняет размер (минимум 420×360), по умолчанию 640×720, запоминает размер и место, не становится вкладкой, поверх полноэкранной карты; кнопка Done и Esc закрывают. iPad: лист заметки с высотой medium/large, полоской для перетаскивания и Done; рукописная заметка — на весь экран с Done.

Проверить вручную: двойной клик по теме → сразу печатать; Tab/Enter → печатать; перетащить тему (линия следует); переместить ветку на соседей (соседи раздвигаются); Services → Layout → Tree Down; карту во весь экран → Add Note (обычное окно поверх, Esc закрывает).

## WP7 — ссылки на темах (2026-11-12)
Тема может быть ссылкой: на веб-адрес или на другую тему этой карты (в том числе плавающую).
- **Значок** перед заголовком, цветом текста темы: цепочка — веб-ссылка, стрелка ↪ — ссылка на тему. Размер темы учитывает значок. Если тему-цель удалили, ссылка остаётся «битой» (значок бледный), Undo удаления её восстанавливает. Подсказка при наведении (Mac): адрес или путь к теме («Central › Beta › Gamma»), для битой — «Target topic was deleted».
- **Меню темы**: первым пунктом (жирным) «Go to “…”», затем в разделе ссылок «Add Link…» / «Edit Link…» (⌘K, также меню Topic и Insert → Link…), «Copy Link», «Remove Link». В меню Topic также «Go to Link», «Remove Link», «Back» (⌘[).
- **Редактор ссылки** (лист): Web | Topic. Web — поле адреса, `https://` добавляется сам, если схемы нет («example.com», «localhost:8080»), неверный адрес подсвечивается, кнопка сохранения неактивна. Topic — поиск по названию и пути, список всех тем с путём; «Pick on Canvas» закрывает лист, и можно кликнуть тему на карте (Esc отменяет), как при создании связи.
- **Go to**: веб — открывается в браузере по умолчанию; тема — свёрнутые родители раскрываются, тема выделяется и плавно прокручивается/приближается в центр. ⌘+клик по теме (Mac) или клик/тап по значку ссылки (Mac и iPad) = Go to; обычный клик только выделяет.
- **Back**: после перехода внизу появляется плашка «‹ Back to “…”» (и ⌘[) — возврат к теме, с которой перешли; стек до 50 шагов, удалённые темы пропускаются. История — состояние окна, не сохраняется и не отменяется.
- **Раскрытие родителей** при Go to — один шаг Undo «Show Topic» (только если что-то было свёрнуто). Почему так: свёрнутость сохраняется в файле и все остальные сворачивания отменяемые; неотменяемое изменение сбило бы историю Undo и не пометило бы документ изменённым.
- Установка/изменение/удаление ссылки — один шаг Undo («Add Link» / «Edit Link» / «Remove Link»). В `map.json` — необязательное поле `link` (`{"kind":"web","url":…}` / `{"kind":"topic","topicID":…}`); старые файлы открываются как раньше, неизвестный тип ссылки (из будущей версии) читается как «без ссылки».

Проверить вручную: ⌘K → ввести «apple.com» → Add Link → ⌘+клик по теме открывает Safari; ⌘K → Topic → найти тему в свёрнутой ветке → Save → клик по значку: ветка раскрылась, тема в центре, внизу «Back» → вернуться; Pick on Canvas → кликнуть тему; удалить тему-цель → значок бледный, Go to → «Target topic was deleted», Undo → ссылка снова работает; на iPad — тап по значку и долгое нажатие → меню. Снимок: `Tools/preview/links.png`.

Ограничения: «Go to» в контекстном меню не выделяется жирным, если система игнорирует стиль текста в меню; ⌘+тап на iPad с клавиатурой не обрабатывается (тап по значку работает); ссылки на файлы — позже.

## WP8 — задачи (2026-11-12)
Любую тему (и плавающую) можно превратить в задачу.
- **На теме**: кружок-чекбокс перед заголовком (перед значком ссылки, если он есть). Клик по кружку отмечает задачу выполненной и обратно (тема при этом выделяется, перетаскивание не начинается; два быстрых клика не считаются двойным кликом и не создают подтему). Выполненная задача: галочка, текст зачёркнут и бледный. Приоритет — «!!!» (высокий, красный), «!!» (средний, оранжевый), «!» (низкий, синий) перед заголовком. Срок — маленькая плашка после заголовка: «Today» (оранжевая), «Tomorrow», день недели, «21 Nov»; просроченная — красная. Размер темы учитывает всё это.
- **Меню темы** (раздел задачи): «Convert to Task»; у задачи — «Mark as Done / Mark as Not Done» (⌘⏎), «Priority» (High/Medium/Low/None), «Due Date» (Today, Tomorrow, Next Week, Choose Date… — всплывающий календарь у темы, Clear Due Date), «Convert to Topic». То же в меню Topic; в меню Insert (тулбар) — «Task». Приоритет или срок на обычной теме сразу делают её задачей.
- **Панель «Tasks (N)»** — карточка на холсте в стиле плавающей темы XMind. Это не тема: она строится на лету из задач карты, не участвует в раскладке и не попадает в дерево. Появляется, когда есть хотя бы одна открытая задача, и плавно исчезает, когда открытых не осталось. Список: просроченные, затем по сроку, затем по приоритету, затем в порядке карты. Строка: чекбокс, цветная точка ветки, приоритет и название, путь (две ближайшие родительские темы), срок. Клик по строке — выделить тему и прокрутить к ней (свёрнутые ветки раскрываются, как в «Go to»). Чекбокс в строке завершает задачу; строка ещё ~1 секунду видна отмеченной, потом исчезает. Больше 10 задач — «Show N More». Меню «…»: Show Completed (показать и выполненные), Reset Position. Стрелка слева сворачивает панель до заголовка.
- **Положение панели**: по умолчанию — справа от карты, по верхнему краю (никогда не закрывает темы и центральную тему; двигается вместе с картой, пока вы её не переставите). Перетащите за заголовок — место сохраняется в файле карты. «Zoom to Fit» учитывает панель.
- **Отмена**: каждое действие — один шаг Undo («Convert to Task», «Complete Task», «Set Priority», «Set Due Date», «Convert to Topic», «Move Tasks Panel», «Collapse Tasks Panel»). Почему перемещение и сворачивание панели отменяемые: они сохраняются в файле, а документ помечается изменённым через историю Undo (как и раскрытие веток при «Go to»). «Show Completed» и «Show N More» — настройки окна, не сохраняются.
- **Файл**: в `map.json` необязательные поля `task` у темы (`isDone`, `priority` 1–3, `dueDate`, `completedAt`) и `taskPanel` у карты (`position`, `isCollapsed`). Старые карты открываются как раньше; испорченные значения читаются как «нет».

Как проверено: тесты модели и Undo, JSON (совместимость, сохранение пакета на диск), сортировка, подписи сроков, правила показа панели, её положение и сохранение; тесты с настоящими событиями мыши (холст и настоящее окно документа): клик по чекбоксу на теме, клик по строке панели (тема в свёрнутой ветке раскрывается и выделяется), выполнение последней задачи скрывает панель (Undo возвращает), перетаскивание панели. Снимок `Tools/preview/tasks.png` просмотрен.

Проверить вручную: правый клик по теме → Convert to Task → клик по кружку; Priority → High; Due Date → Choose Date… → вчерашний день (плашка красная); справа появилась панель — клик по строке, отметить чекбокс в панели (строка исчезает), когда задач не осталось — панель исчезает; перетащить панель, закрыть и открыть карту — место сохранилось; ⌘⏎ на выделенной задаче. На iPad — тап по кружку и по строке, долгое нажатие → меню задачи.

Ограничения: задачи меняются по одной теме (нет множественного выделения); список в панели не прокручивается (растёт через «Show N More»); переставленная вручную панель может лечь поверх тем (она всегда сверху); всплывающий календарь и касания на iPad тестами не проверены.

## WP10 — ссылки на другие карты (2026-11-12)
Тема может ссылаться на другой файл `.mindmap` (по желанию — на конкретную тему в нём).
- **Значок** «карта» перед заголовком. Подсказка (Mac): «Open map “Roadmap” in a new tab — Roadmap.mindmap» (путь относительно папки текущей карты).
- **Открытие**: «Go to» / ⌘+клик / клик по значку. **Mac**: карта открывается **новой вкладкой этого же окна** (системные вкладки окон). Если она уже открыта — выводится на передний план её вкладка/окно, второй раз не открывается. Если в ссылке указана тема — она выделяется и прокручивается к центру (свёрнутые ветки раскрываются, как в WP7). **iPad**: карта открывается **в новом окне** (multi-window; уже открытая — её окно выводится вперёд). Почему окно, а не своя панель вкладок: на iPad окна и есть «вкладки» системы (переключатель приложений, Stage Manager, Split View, восстановление по окнам), и каждое окно уже ведёт свой документ. Где несколько окон недоступно, текущее окно переключается на карту, а в панели появляется «‹ Back to “…”».
- **Редактор ссылки** (⌘K): Web | Topic | **Map**. Choose… — выбрать `.mindmap`; **New Map…** — создаёт пустую карту рядом с текущей, с именем темы («Q3 Plan.mindmap», при совпадении «Q3 Plan 2»), и сразу связывает. На Mac приложение работает в песочнице и не может само писать в папку документа — тогда открывается окно сохранения с этим именем; так же, если карта ещё не сохранена. «Open at topic» — список тем выбранной карты с поиском (по умолчанию «Whole map»).
- **Хранение**: относительный путь от папки текущей карты (работает, если папка карт синхронизирована через iCloud Drive или скопирована на другое устройство) + закладка (bookmark; на Mac — с правом доступа песочницы) как запасной вариант. Порядок поиска: путь → закладка (устаревшая обновляется, путь и имя переписываются) → «не найдено». Для ещё не сохранённой карты хранится только закладка; путь добавляется, когда у карты появляется файл (без отдельного шага Undo; записывается со следующим сохранением).
- **Файл не найден**: «Go to» показывает «Open Map: “X” could not be found…» с кнопками Locate… / Remove Link / Cancel; в меню темы — «Locate…». Выбранный файл заменяет ссылку (один шаг Undo, тема-цель сохраняется).
- Установка/изменение/удаление — один шаг Undo, как в WP7. В `map.json`: `{"kind":"map","path":"Roadmap.mindmap","bookmark":…,"name":"Roadmap","topicID":…}`. Исправлено ограничение WP7: ссылка неизвестного типа (из будущей версии) теперь **сохраняется как есть**, а не теряется при сохранении.

Как проверено: тесты модели, Undo, JSON (в т.ч. сохранение неизвестных ссылок), относительные пути, поиск файла (путь / закладка / перемещённый файл / нет файла), «New Map…» на диске, Go to / Locate в редакторе; тест с настоящими событиями на Mac: ⌘+клик в реальном окне документа открывает вторую карту вкладкой того же окна (проверено `tabbedWindows`, выбранная вкладка, тема в свёрнутой ветке выделена), повторный ⌘+клик выводит существующую вкладку. Снимки: `Tools/preview/map-links.png` (значки), `Tools/preview/map-tab-ipad.png` (вкладка Map на iPad); на симуляторе iPad ссылка открыла второе окно «Roadmap» с выделенной темой Q3.

Проверить вручную: Mac — ⌘K → Map → New Map… (окно сохранения) → ⌘+клик по теме: новая вкладка; вернуться на первую вкладку, ⌘+клик ещё раз — переключение на ту же вкладку; переименовать/удалить файл в Finder → Go to → Locate…. iPad — тап по значку карты открывает второе окно; повторный тап выводит его вперёд.

Ограничения: значок не бледнеет, если файл пропал (проверяется при переходе и в меню); отмена ссылки на созданную «New Map…» карту не удаляет файл; ссылка на саму текущую карту в редакторе запрещена (для этого есть Topic); режим «Back» на iPad без многооконности и открытие вкладкой при полноэкранном окне Mac вручную не проверялись.

## Отзыв, партия 2 — множественное выделение и границы вокруг любых тем (2026-11-12)
**Множественное выделение (как в XMind)**
- ⌘+клик — добавить/убрать тему; ⇧+клик — добавить (если тема — соседка основной выделенной, выделяется весь диапазон соседей между ними); ⌘A — все видимые темы; Esc — остаётся только основная тема (на ней фокус клавиатуры).
- Рамка выделения: перетаскивание по пустому месту с зажатым ⇧ или ⌘ рисует прямоугольник, задетые темы добавляются к выделению (видно сразу во время перетаскивания). Обычное перетаскивание по фону по-прежнему двигает карту.
- iPad: кнопка «Select» в панели инструментов — режим, в котором тап добавляет/убирает тему, а протягивание по фону рисует рамку; сверху плашка «N selected · Done». Долгое нажатие на выделенную тему открывает меню для всего выделения.
- Все выделенные темы обведены; основная — чуть толще и ярче.
- Действия над выделением — каждое **один шаг Undo**: Delete (если выделены и тема, и её предок — считается только предок); перетаскивание любой выделенной темы тащит все (у каждой свой «призрак» и живая линия): на тему — все становятся её детьми в прежнем порядке, на край соседней темы — вставляются туда все подряд, на пустое место — все сдвигаются на одно и то же смещение; меню Format (цвет, форма, рамка, линия, раскладка, «Apply to Branch»), свернуть/развернуть, Convert to Task / Mark as Done / Convert to Topic, Add Boundary.
- Контекстное меню выделенной темы при нескольких выделенных: заголовок «N Topics», затем только групповые действия и «Delete N Topics».
- Попутно: на Mac клавиша Backspace на холсте раньше доходила как U+007F и не распознавалась обработчиком клавиш (работала только через пункт меню) — теперь распознаётся.
- Важно: ⌘+клик по теме **со ссылкой** по-прежнему выполняет «Go to» (так было заказано в WP7/WP10). Такую тему можно добавить к выделению ⇧+кликом. Если удобнее, чтобы ⌘+клик всегда выделял, а переход был, например, на ⌥⌘+клик — скажите.

**Границы вокруг произвольных тем**
- Граница теперь хранит список участников `memberIDs` (каждый участник — со своим видимым поддеревом), например один ребёнок темы A и один ребёнок темы B. Создание — из текущего выделения: ⌘B, кнопка Boundary, меню. Центральная тема участником быть не может.
- Старые файлы (`nodeID` + `siblingIDs`) открываются как участники `[nodeID] + siblingIDs`. Новые файлы дополнительно пишут `nodeID` (первый участник), чтобы старые версии приложения тоже могли их открыть.
- Отрисовка: если участники рядом и между ними нет чужих тем — один скруглённый прямоугольник. Иначе — один общий контур: области участников (с отступом) соединяются узкой «перемычкой», которая прокладывается в обход других тем (поиск кратчайшего пути по сетке с минимумом поворотов); прямоугольные углы скругляются, мелкие ступеньки выравниваются. Все участники всегда внутри контура; чужие темы — только если обойти их невозможно. Подпись — вкладка в левом верхнем углу области первого участника. Штриховка, пунктир, выбор и меню — как раньше; клик попадает только по линии контура и вкладке.
- Раскладка: вокруг каждого участника резервируется отступ, поэтому соседние темы не залезают под контур (перемычки могут пересекать соединительные линии).
- Удаление участника убирает его из границы; удаление последнего — удаляет границу; Undo всё возвращает. Перемещённый участник остаётся участником, контур следует за ним. Свёрнутые участники не рисуются, но остаются в границе.
- Изменение состава: выбрать границу → меню «Edit Members…» → текущие участники становятся выделением, клики добавляют/убирают темы, сверху плашка с Cancel / Done; Done сохраняет состав (один шаг Undo, пустой состав удаляет границу), Esc — отмена.

Как проверено: тесты логики выделения (⌘/⇧-клик, диапазон соседей, ⌘A, Esc, рамка, отбор предков), групповые удаление/перенос/вставка/свободный сдвиг/формат/задачи — каждый один шаг Undo; миграция и JSON границ; геометрия контура (участники далеко друг от друга — все внутри, чужие темы снаружи, соседние участники — прямоугольник, вложенные и свёрнутые); тесты с настоящими событиями мыши/клавиатуры на Mac (голый холст и настоящее окно документа): ⌘+клик по двум темам → Delete (Undo одним шагом), перетаскивание выделения на тему, ⇧+перетаскивание по фону рисует рамку и не двигает карту. Снимки просмотрены: `Tools/preview/boundary-cross-branch.png` (граница вокруг «Pricing» и «Mobile app» из разных веток обходит остальные темы справа; соседние «Launch plan» + «Public API» — один прямоугольник; выделены две темы), `Tools/preview/boundary-both-sides.png` (участники по разные стороны центральной темы).

Проверить вручную: Mac — ⌘+клик по трём темам, правый клик → «3 Topics» → Color; перетащить одну из них на другую тему; ⇧+протянуть по фону; ⌘B на двух темах из разных веток, затем Edit Members… iPad — кнопка Select, тапы, протягивание рамки, долгое нажатие → меню выделения, перетаскивание группы пальцем.

Ограничения: на iPad ⌘/⇧+тап с аппаратной клавиатурой не поддержан (используйте режим Select); перемычка может пройти по соседней границе или линиям связей; при анимации раскладки форма сложного контура меняется скачком (рамка анимируется); «призраки» при перетаскивании группы — только сами выделенные темы, без их поддеревьев (как и при одиночном перетаскивании).

## Сборка и запуск
Xcode установлен, но не выбран — всегда указывать `DEVELOPER_DIR`:
```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcodebuild -project MindMap.xcodeproj -scheme MindMap -destination 'platform=macOS' test
xcodebuild -project MindMap.xcodeproj -scheme MindMap -destination 'generic/platform=iOS Simulator' build
xcodebuild -project MindMap.xcodeproj -scheme MindMap -destination 'platform=iOS Simulator,name=iPad Pro 11-inch (M5),OS=latest' test
```
Запуск: открыть `MindMap.xcodeproj` в Xcode, схема `MindMap`, выбрать «My Mac» или iPad и нажать Run. Для запуска на устройстве указать свою команду подписи в Signing & Capabilities вместо ad-hoc. На Mac новая карта создаётся через File → New, на iPad — через кнопку с папкой → New Map.
