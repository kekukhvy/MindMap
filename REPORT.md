# MindMap — отчёт по Stage 1 (редактор дерева)

Нативное SwiftUI-приложение (iPadOS 17+ / macOS 14+), один мультиплатформенный таргет, без сторонних зависимостей.
Сборка iPad Simulator + macOS: 0 ошибок, 0 предупреждений. 101 тест (Swift Testing) зелёные на macOS и iPad Simulator.

## Что работает
**Модель и документ**
- Дерево `Node`: текст, цвет-тег или свой цвет, свёрнутость, стиль раскладки, форма, рамка, стиль/толщина/пунктир линии, вложения (пока заглушка).
- Документ-пакет `.mindmap` = `map.json` + `attachments/`. При сохранении `attachments/` и неизвестные файлы пакета переиспользуются как есть, не переписываются (в iCloud это дёшево). В JSON только UUID и относительные имена, абсолютных путей нет.
- Обратная совместимость: старый `map.json` только с `root` (даже без `formatVersion`) открывается; неизвестные значения enum заменяются значениями по умолчанию.
- Undo/redo: каждое изменение структуры и стиля — ровно один шаг (тест на 31 вид операций). Добавление темы + первое переименование — один шаг. После автосохранения переименование регистрируется отдельно, и документ снова помечается изменённым.

**Раскладка и отрисовка (стиль XMind)**
- Сбалансированная карта, вправо, влево, дерево вниз, оргсхема — на любой ветке; без перекрытий при разных размерах узлов.
- Центральная тема — жирный блок, главные ветки — цветные заливки, подтемы — подчёркнутые. Радужная или монохромная тема, цвет наследуется веткой.
- Формы, рамки, линии ветвей (кривая, прямая, угол, скруглённый угол; сужение от центра).
- Плавающие темы, связи (кривая со стрелками, подпись, перетаскиваемые контрольные точки), границы (пунктир + штриховка, подпись).
- Длинный текст переносится по ширине 240 pt и обрезается после 8 строк (полный текст виден в редакторе), поэтому узлы остаются компактными. Узел с пустым текстом имеет минимальный размер и кликабелен.
- Скорость (debug-сборка, Mac): раскладка 1000 узлов ≈ 2–3 мс; перерисовка на нажатие клавиши при 1000 узлах ≈ 4 мс. Размеры текста кэшируются, перемеряется только редактируемый узел.

**Взаимодействие**
- Клавиатура:
  - Enter — соседняя тема, Tab — дочерняя, Delete — удалить.
  - Переименовать: Space, F2, пункт «Rename» (первый в контекстном меню) или просто начать печатать на выбранной теме.
  - Стрелки — переход по соседним темам на карте.
  - Cmd+/ — свернуть/развернуть; Cmd+Option+1…4 — показать уровни 1–4, Cmd+Option+0 — развернуть всё; Cmd+Z / Cmd+Shift+Z — отмена/повтор.
  - Cmd+L — связь, Cmd+B — граница; Cmd+= / Cmd+- / Cmd+0 — масштаб.
  - Во время редактирования клавиши уходят в текстовое поле.
- Мышь и тач:
  - Тап — выбор. Двойной клик / двойной тап по теме — новая дочерняя тема (сразу в режиме ввода, как Tab). Двойной клик по пустому месту — плавающая тема.
  - Перетаскивание на центр темы — перенос; на край — вставка до/после, с индикатором; на пустое место — тема остаётся там, куда её бросили (свободная позиция, соседи перестраиваются без неё; в сбалансированной карте сторона определяется позицией). С Option (Mac) — всегда свободное перемещение, даже над темами. «Reset Position» / «Reset All Positions» возвращают авто-раскладку.
  - Тему можно тащить и во время редактирования (за край/поля вокруг текста) — текст сохраняется.
  - Перетаскивание плавающей темы — перемещение.
  - Кнопка −/+N на краю темы, откуда выходят ветки (как в MindManager): видна при наведении (Mac), у выбранной и у свёрнутой темы; клик сворачивает/разворачивает, не начиная перетаскивание.
  - Меню Outline (тулбар), View (меню Mac), контекстное меню центральной темы и пустого холста: Collapse to Level 1–4, Expand All, Reset All Positions. У темы: Expand Branch / Collapse Branch. Каждое действие — один шаг отмены.
  - Правый клик или долгое нажатие — контекстное меню.
  - Меню Format: раскладка, форма, рамка, цвет, линия, тема, «применить к ветке».
- Подписи связей и границ редактируются прямо на холсте, а не в алерте. Return, Esc или клик в сторону — сохранить; пустая подпись удаляется.
- Масштаб 0.2×–4×: pinch, на Mac также Cmd+колёсико или трекпад. Панорама — перетаскиванием фона или прокруткой.

**Запуск без выбора файла (п. 16)**
- Mac: при запуске окно выбора файла не показывается. Если macOS сама восстановила окна (или несохранённый документ), используются они. Иначе открывается последний документ из «Open Recent». Если его нет, открывается следующий из списка, а если и его нет — новая пустая карта. Другие файлы — через File → Open / Open Recent.
- iPad: браузер документов не показывается. Окно сразу открывает редактор:
  - свой документ (после перезапуска окна);
  - иначе последний открытый документ (только первое окно);
  - иначе новую карту «Untitled», «Untitled 2», …
- Новые карты сохраняются в папку приложения: Files → «На iPad» → MindMap. Если включить iCloud (см. ниже), они сохраняются в iCloud Drive → MindMap.
- Кнопка с папкой слева в тулбаре открывает меню:
  - New Map;
  - Open… — выбор .mindmap где угодно, включая iCloud Drive;
  - Rename….
- С клавиатурой: Cmd+N — новая карта, Cmd+O — открыть, Opt+Cmd+N — новое окно. Файл, открытый из Files, открывается в текущем окне.
- Каждое окно iPad редактирует свой документ, и один файл не открывается в двух окнах.
- Undo/redo, автосохранение и пометка изменений работают как раньше: документ использует undo manager окна, и его же использует системное меню Edit.
- Пустая новая карта, которую так и не изменили, удаляется при переходе к другому документу, чтобы не копились лишние «Untitled».

## Исправлено в WP3
- **Падение при повторном сохранении существующего документа.** Установка `preferredFilename` у переиспользованной папки `attachments/` бросала NSGenericException. Исправлено, покрыто тестом записи на диск.
- Переименование новой темы после автосохранения не помечало документ изменённым.
- При переносе или отсоединении тема теперь удаляется из диапазонов соседей у границ; раньше там оставались «висячие» ссылки.
- Тема, выросшая после ввода текста, прокручивается в видимую область.
- Алерт подписи заменён на редактирование прямо на холсте.
- Новые тесты:
  - undo/redo всех операций; некорректные операции не создают шаг отмены;
  - очистка связей и границ при удалении;
  - пакет с вложениями через запись на диск; старый JSON;
  - длинный и пустой текст; пределы масштаба;
  - сворачивание ветки с выделением внутри; подписи на холсте;
  - скорость; рендер нового документа.

## Проверить вручную на iPad
1. Files / iCloud Drive:
   - создать документ, закрыть, открыть снова;
   - переименовать и переместить в Files;
   - открыть тот же файл на Mac через iCloud;
   - запуск: сразу открывается последний документ; если его удалить — новая карта; открыть файл из Files; два окна (Split View) с разными картами; Rename…;
   - правки сохраняются, в том числе после фонового автосохранения и сворачивания приложения;
   - повторное сохранение не падает.
2. Аппаратная клавиатура:
   - Tab создаёт дочернюю тему, а не переключает фокус; так же при редактировании;
   - Enter, Delete, Space, стрелки;
   - Esc — выход из редактирования и отмена режима выбора цели;
   - Cmd+Z / Cmd+Shift+Z, Cmd+/, Cmd+L, Cmd+B;
   - у новой темы выделен весь текст; ввод буквы на выбранной теме начинает редактирование.
3. Палец:
   - тап; двойной тап по теме (новая дочерняя тема) и по пустому месту (плавающая тема);
   - перетаскивание темы на пустое место (свободная позиция), кнопка −/+ у выбранной темы;
   - перетаскивание на тему и между соседями;
   - долгое нажатие — меню, тема выбирается заранее.
4. Apple Pencil: тап и перетаскивание работают как пальцем, долгое нажатие открывает меню.
5. Трекпад и мышь: панорама двумя пальцами, pinch-зум, правый клик (меню), наведение при выборе цели связи.
6. Pinch-зум пальцами: плавный, точка под пальцами остаётся на месте, пределы 0.2×–4×, текст чёткий.
7. Многозадачность:
   - два окна приложения (Split View / Stage Manager) с разными документами и с одним и тем же;
   - клавиши работают в активном окне;
   - при изменении размера окна карта не сдвигается.
8. Подпись связи или границы на холсте: экранная клавиатура не перекрывает поле.
9. Большая карта (сотни тем): плавность панорамы и набора текста.

## Известные ограничения
- Редактор темы однострочный: текст отображается с переносами, но ввести перевод строки нельзя.
- Граница — только вокруг одного поддерева: нет множественного выделения для диапазона соседей. Диапазон из файла рисуется, но места не резервирует.
- Перестановка в сбалансированной карте следует порядку детей: после перебалансировки ветка может перейти на другую сторону.
- На iPad нет контекстного меню пустого холста (вместо него — двойной тап и меню Insert в тулбаре).
- Tab на iPad перехватывается холстом на уровне окна: в текстовых полях листов (например, hex-цвет) Tab не переключает поля.
- Не проверено автоматически:
  - XCUITest невозможен в этой среде (Automation Mode выключен и требует подтверждения пользователя). Вместо него `CanvasEventTests` подают синтезированные события мыши в настоящий SwiftUI-холст на macOS — и в отдельном окне, и в реальном окне документа DocumentGroup (тулбар, меню, монитор событий): клик, двойной клик, перетаскивание (перенос, вставка, свободная позиция, Option), панорама фоном, перетаскивание редактируемой темы, кнопка −/+. Прокрутка трекпадом, наведение и iPad-жесты так не проверены;
  - синхронизация iCloud и конфликты версий;
  - клавиатура, Pencil и трекпад на устройстве.
  Рендер проверен только снимком вне экрана (ImageRenderer) на macOS; приложение на Mac запускается.
- iCloud на iPad выключен: нужна команда разработчика (у ad-hoc и бесплатных команд iCloud нет). Чтобы включить, в Signing & Capabilities добавьте iCloud → iCloud Documents с контейнером `iCloud.com.kekukh.MindMap` (в Info.plist `NSUbiquitousContainers` уже есть). Без этого новые карты лежат в «На iPad › MindMap», а файлы из iCloud Drive открываются через Open….
- iPad: незаметно закрытое окно (не через переход в фон) сохраняется периодическим автосохранением UIDocument и при уходе приложения в фон. Конфликт версий iCloud решается в пользу текущей версии.
- Stage 2: готовы WP4 (Markdown-заметки) и WP5 (рукописные заметки), см. разделы ниже; вложения-файлы (WP6) ещё не сделаны.

## Stage 2 · WP4 — Markdown-заметки
Что работает:
- У темы может быть несколько вложений. На теме справа от текста — маленькие значки: «≡» заметка, каракуля (рисунок), скрепка (файл). Больше трёх — по значку на вид и счётчик (по нажатию — список). Содержимое в карточке не показывается.
- Добавить заметку: контекстное меню темы → «Add Note», кнопка «Note» в центральной группе тулбара или ⇧⌘N (открывает первую заметку темы или создаёт новую). Новая заметка начинается строкой `# <текст темы>`.
- Открыть: нажать значок на теме или пункт в контекстном меню (там же Move Left/Right и Remove). На iPad заметка открывается листом (Done), на Mac — отдельным окном.
- Редактор: поле заголовка, простой текстовый редактор Markdown (моноширинный шрифт — переключатель «Aa»), Edit/Preview, Undo/Redo. Правки заметки входят в общую историю отмены документа (⌘Z работает и в окне заметки), документ помечается изменённым и автосохраняется.
- Хранение: `Карта.mindmap/attachments/<UUID>.md` — обычный UTF-8 Markdown, открывается в Obsidian. Неизменённые файлы при сохранении не переписываются; файлы, на которые никто не ссылается, удаляются при сохранении, но удаление заметки или темы можно отменить — файл вернётся.
- Mac: окно заметки, восстановленное после перезапуска без открытой карты, показывает «Map Not Open»; при закрытии карты её окна заметок закрываются.

Проверить вручную:
1. iPad: добавить заметку, набрать текст, Done, закрыть приложение, открыть снова — текст на месте; ⌘Z в листе с аппаратной клавиатурой.
2. Mac: два окна заметок от разных карт; закрыть карту — окна закрываются; перезапуск с открытым окном заметки.
3. Открыть `attachments/<UUID>.md` в Obsidian/TextEdit через «Показать содержимое пакета».
4. Удалить тему с заметкой, сохранить, отменить — заметка и её текст вернулись.

Ограничения: Preview — упрощённый Markdown (заголовки, списки, задачи, цитаты, код, inline-стили); значки нельзя переставлять перетаскиванием (только меню); файлы пока открываются заглушкой.

Исправлено в WP5: при открытом листе заметки главный поток мог загружаться на 100%. Причина: окно карты и редактор вложения обновляли кнопки Undo/Redo по уведомлению checkpoint, а сама проверка `canUndo` снова отправляет это уведомление — получался бесконечный цикл. Теперь кнопки обновляются только при закрытии группы и при undo/redo.

## Stage 2 · WP5 — рукописные заметки (PencilKit)
Что работает:
- Добавить: контекстное меню темы → «Add Handwritten Note», тулбар «+» (Insert) → «Handwritten Note», меню Topic → «Add/Open Handwritten Note» или ⇧⌘D (открывает первую рукописную заметку темы или создаёт новую). На теме появляется значок-каракуля; нажатие на него открывает заметку.
- iPad: заметка открывается на весь экран (холст PencilKit + стандартная панель инструментов: ручки, маркер, ластик, линейка, цвета). Есть поле заголовка, Undo/Redo и Done.
  - По умолчанию рисует только Apple Pencil, а палец прокручивает (как в «Заметках»). Переключатель с рукой в тулбаре («Draw with Finger») разрешает рисовать пальцем; настройка запоминается.
  - Двойное касание и сжатие Pencil обрабатывает системная панель инструментов.
  - Лист «бесконечный» вниз: когда пишешь у нижнего края, страница растёт. Pinch-зум до 5×, по умолчанию страница по ширине экрана (ширина страницы 1024 pt одинакова на iPad и Mac).
  - Бумага всегда белая, чернила не инвертируются и в тёмной теме.
- Отмена: каждая серия штрихов (пауза 0,6 с, не дольше 2 с) — один шаг «Draw» в общей истории документа, вместе с картой и заметками. Встроенная отмена PencilKit отключена, чтобы шаги не дублировались. ⌘Z, жест тремя пальцами, кнопки панели Pencil и тулбара отменяют шаги документа, холст сразу показывает результат. Несохранённые штрихи записываются по Done, перед Undo и при уходе приложения в фон. Документ помечается изменённым и автосохраняется.
- Хранение: `Карта.mindmap/attachments/<UUID>.drawing` — ровно `PKDrawing.dataRepresentation()`. Удаление заметки или темы можно отменить даже после сохранения.
- Mac: заметка открывается отдельным окном (как текстовая) и показывает рисунок на белой странице. Масштаб — pinch или ⌘+колёсико; страница подгоняется по ширине окна, пока вы сами не изменили масштаб. Внизу подсказка, что полноценно рукописные заметки редактируются на iPad.
  - Бонус: простое рисование мышью. Инструменты View / Pen / Eraser, 4 цвета пера, ластик удаляет штрих целиком. Каждый штрих — шаг «Draw», ⌘Z в окне отменяет его.

Как проверено: тесты моделей и хранилища (рисунок с синтетическими штрихами сохраняется в пакет на диск и читается обратно без изменений; отмена добавления, удаления и рисования; очистка «осиротевших» `.drawing`; совместимость JSON). На симуляторе iPad сделаны и просмотрены скриншоты через DEBUG-переменную `MINDMAP_DEBUG_DRAWING=icon|sheet|undo`: холст с заранее заданным рисунком; тёмная тема; появление и исчезновение штриха при Draw/Undo; значок на теме. На Mac настоящие события мыши проверены в окне документа: клик по значку открывает окно с рисунком (снимок окна просмотрен), штрих мышью, ⌘Z, ластик.

Проверить вручную на iPad с Apple Pencil:
1. Добавить рукописную заметку из меню темы и через ⇧⌘D. Написать несколько слов. Done → значок на теме → снова открыть: всё на месте. Закрыть приложение и открыть снова: рисунок сохранился.
2. По умолчанию палец не рисует, а прокручивает; Pencil рисует. Включить «Draw with Finger»: палец рисует, прокрутка двумя пальцами. Перезапустить: настройка сохранилась.
3. Двойное касание Pencil (2-го поколения / Pro) переключает ручку и ластик; сжатие (Pencil Pro) показывает палитру у кончика.
4. Undo/Redo: кнопки тулбара, кнопки на панели Pencil, жест тремя пальцами, ⌘Z на клавиатуре. Быстро написать штрих и сразу нажать Undo — штрих отменяется, ничего не теряется. После Done ⌘Z на карте отменяет рисунок шаг за шагом, затем само добавление.
5. Писать у нижнего края: страница растёт, прокрутка вниз продолжается. Pinch-зум, поворот экрана: страница остаётся по ширине.
6. Тёмная тема: бумага белая, чёрные чернила остаются чёрными; цвета палитры не инвертируются.
7. Отклонение ладони при письме Pencil; линейка; разные инструменты (карандаш, маркер, ластик пикселей и объектов).
8. Открыть ту же карту на Mac: окно рисунка совпадает с iPad. Нарисовать мышью, вернуться на iPad — штрих виден.

Ограничения: на Mac нет полноценного редактора PencilKit (PKCanvasView там нет) — только просмотр и простое рисование мышью: перо постоянной толщины, ластик удаляет штрих целиком, без лассо. Нет миниатюры рисунка при наведении на значок. Настоящий Pencil, жесты и отклонение ладони в симуляторе не проверить — см. список выше.

## Сборка и запуск
Xcode установлен, но не выбран — всегда указывать `DEVELOPER_DIR`:
```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcodebuild -project MindMap.xcodeproj -scheme MindMap -destination 'platform=macOS' test
xcodebuild -project MindMap.xcodeproj -scheme MindMap -destination 'generic/platform=iOS Simulator' build
xcodebuild -project MindMap.xcodeproj -scheme MindMap -destination 'platform=iOS Simulator,name=iPad Pro 11-inch (M5),OS=latest' test
```
Запуск: открыть `MindMap.xcodeproj` в Xcode, схема `MindMap`, выбрать «My Mac» или iPad и нажать Run. Для запуска на устройстве указать свою команду подписи в Signing & Capabilities вместо ad-hoc. На Mac новая карта создаётся через File → New, на iPad — через кнопку с папкой → New Map.
