# MindMap — plan & status (source of truth for resuming work)

Native mind-map app, SwiftUI multiplatform (iOS/iPadOS 17+, macOS 14+). "XMind speed + Mindjet attachments".
Orchestrator delegates implementation to agents; each agent updates the STATUS section below before finishing.

## Environment notes
- Xcode is at /Applications/Xcode.app but NOT selected. Always prefix: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild ...`
- No xcodegen. Project file is hand-written; prefer Xcode 16 synchronized folders (PBXFileSystemSynchronizedRootGroup) so new files need no pbxproj edits.
- Build targets: iPad simulator (`-destination 'generic/platform=iOS Simulator'` or a named iPad) and macOS (`platform=macOS`). Zero errors AND zero warnings required.

## Product rules (all stages)
- Node stays compact: short text, color tag, icons. Attachments shown as small icons on node; open in sheet (iPad) / separate window (macOS). Never inside the card.
- Swift 5.9+, SwiftUI, @Observable, SPM only, no third-party deps.
- DocumentGroup + FileWrapper package: `map.json` (tree) + `attachments/` (UUID-named files). Must work from iCloud Drive/Files.
- Markdown attachments = plain `.md` (Obsidian-readable). Handwriting = PencilKit PKDrawing data.
- Folders: Model/, Layout/, Views/, Document/. Small files.

## Stage 1 — tree editor: COMPLETE pending user confirmation (manual iPad checklist in REPORT.md). Do NOT start Stage 2 until user confirms.
1. Model: `Node` (id, text, isCollapsed, colorTag, children, attachments: [Attachment] placeholder). Central root.
2. Layout: pure, unit-tested struct; horizontal tree, children right of parent, vertically centered, no overlaps with variable node sizes.
3. Rendering: pan/zoom canvas (pinch/scroll/trackpad), curved connectors, selected highlight.
4. Keyboard: Enter=sibling, Tab=child, Delete=remove, Space/double-click=edit, Cmd+Z/Cmd+Shift+Z undo/redo, arrows=move selection, Cmd+/=collapse/expand.
5. Touch/mouse: tap select, drag node to reparent, long-press/right-click context menu.
6. UndoManager for every structural change.
7. Save/open document package (map.json only for now).
8. (user, added 2026-11-11) Look & feel as close to XMind as possible: root = bold rounded box, main branches = colored filled rounded topics, subtopics lighter/underlined text, smooth tapered curves from parent edge, branch color inherited by subtree.
9. (user, added 2026-11-11) Per-subtree layout styles (MindManager-like): `Node.layoutStyle: LayoutStyle?` (nil = inherit). Styles: balancedMap (root default, left+right), rightMap, leftMap, treeDown (children one under another, indented; e.g. "Services" branch), orgChartDown. Any sub-branch can override → its own tree. Undoable; persisted. UI: style picker in context menu / toolbar for selected node (WP2).
10. (user, added 2026-11-11) Per-node topic shape: `shape: NodeShape?` (roundedRect, rectangle, capsule, underline, plainText; nil = XMind default by depth) + `borderStyle` (solid/dashed). UI (WP2): Format menu for selected node with "apply to branch" option; one undo group.
11. (user, added 2026-11-11) Color theme: map-level rainbow (XMind multicolor per main branch) or mono(color); per-node/branch custom color override.
12. (user) Floating topics (free-positioned, own subtree), Relationships (cross-links between any nodes, curved arrow + label), Boundaries (grouping: dashed/hatched outline around subtree). Model+layout in WP1, rendering/UI in WP2 (may split to WP2b if large).
13. (user) Line styles: branch connectors per node (curved/straight/elbow/roundedElbow, inherited) + relationship styles (path, solid/dashed/dotted, start/end arrowheads none/arrow/filled/dot/diamond, width, color).
14. (user, 2026-11-12) Free positioning: drop on empty space = manual position (`Node.manualPosition`), node leaves auto-balancing, siblings re-flow; "Reset Position". Click scheme: double-click topic = add child, Enter = sibling, Rename via context menu (+ Space/F2/typing). Double-click empty canvas = floating topic.
15. (user, 2026-11-12) +/− collapse toggle on topic edge (MindManager), menu Collapse to Level 1–4 / Expand All / Expand-Collapse Branch (one undo step each, Cmd+Opt+1..4/0).
Tests: layout + model ops (add, delete, reparent, collapse, undo).
Final report: what works, what to test manually on real iPad, known gaps.
